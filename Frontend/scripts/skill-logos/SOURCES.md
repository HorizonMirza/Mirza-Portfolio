# Sumber logo skill

Sumber SVG untuk logo globe Keahlian Teknis. Situs memuat versi WebP 144 px di `Frontend/public/skills/`, dibuat dengan `pnpm logos:build`. Isi SVG sudah diperiksa: tanpa script, event handler, atau tautan luar. Semua logo adalah merek dagang pemiliknya masing-masing dan hanya dipakai untuk menunjukkan alat yang dikuasai. Kredit singkat tampil di halaman Privasi (bagian Kredit).

- **Devicon v2.17.0** (MIT, lisensi di bawah), varian `*-original`: TypeScript, JavaScript, Python, C++, Java, HTML5, CSS3, React, Next.js, Tailwind CSS, Bootstrap, Node.js, Laravel, FastAPI, PostgreSQL, MySQL, Supabase, Git (Jason Long, CC BY 3.0), GitHub, Vercel, VS Code, Figma, Canva. Logo C dari Devicon v2.15.1 (`c-original`). https://github.com/devicons/devicon
- **Word, Excel, PowerPoint:** ikon produk resmi Microsoft dari CDN Fluent (`res.cdn.office.net/.../brand-icons/product/svg/*_48x1.svg`).
- **Claude:** `claude.ai/favicon.svg` (Anthropic).
- **Codex:** logo OpenAI (path Simple Icons v12.0.0, CC0), hitam seperti aslinya, dibalik di tema gelap.
- **Kiro:** `kiro.dev/icon.svg` (Amazon), utuh.
- **Google Antigravity:** `antigravity.google/favicon.svg` (Google), lingkaran latar dan gaya tema dihapus, logo utuh.

Ikon satu warna cadangan (`Frontend/src/features/skills/brand-icons.ts`) memakai Simple Icons (CC0) dan logo Java (`java-plain.svg`) dari Devicon; atribusinya ada di kepala berkas itu.
